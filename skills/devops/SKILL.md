# DevOps skill

- Inspect the runtime, repository, and current service state before acting.
- Prefer reversible, observable changes and capture a rollback plan before deployments or configuration changes.
- Require explicit confirmation for privileged commands, destructive cleanup, production changes, credential rotation, and network exposure.
- Validate configuration, health, logs, and exit status after every change.
- Do not print secrets from environment variables, service files, logs, or command output.
