# Coding skill

- Inspect repository structure, instructions, and tests before changing code.
- Make the smallest coherent change, preserve existing interfaces, and avoid unrelated formatting churn.
- After edits, run syntax checks and the narrowest relevant tests, then the full suite when practical.
- Do not claim a fix without evidence; include changed files, verification results, and remaining limitations.
- Never expose secrets from environment files, credentials, or private configuration in output.
